# Contributing

Read [the repository instructions](AGENTS.md) and describe the observable change, verification, and relevant recovery path. Check user and upstream authorization before publishing. Keep edits focused, preserve the original behavior of existing tools, and use the existing platform matrix for regression checks.

Only portable, shareable source belongs in Git. Machine plans, inventory, deployment state, rollback snapshots, credentials, and third-party assets with unverified terms stay local. Generated catalog changes should accompany their source change. Use [the PR Kit](pr-authoring-kit/README.md) when a pull request is appropriate.
